# Claude

Репозиторий для экспериментов и небольших проектов, сделанных вместе с [Claude](https://claude.com/product/claude-code).

## Как начать

Склонируйте репозиторий и перейдите в его папку:

```bash
git clone https://github.com/technologsps-cmyk/Claude.git
cd Claude
```

## Как предложить изменение

1. Создайте ветку от `main`: `git switch -c my-change`.
2. 2. Внесите правки и закоммитьте их: `git commit -am "Описание изменения"`.
   3. 3. Отправьте ветку: `git push -u origin my-change`.
